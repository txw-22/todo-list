01 / WORKSPACE

메뉴 하나로 나누어 보는 할 일

사이드바의 네 가지 메뉴로 현재 필요한 항목만 골라 확인할 수 있습니다.

▦

전체 할 일

미완료와 완료를 포함한 모든 항목을 표시합니다. 할 일 전체 현황을 확인할 때 사용합니다.

☀️

오늘

마감일이 오늘인 항목을 표시합니다. 브라우저의 로컬 날짜를 기준으로 판단합니다.

🗓️

✓

완료된 할 일

done === true인 항목만 보여줍니다. 완료 취소 시 목록이 갱신됩니다.

현재 확인된 코드에서는 오늘·예정된 할 일의 필터가 날짜만 확인하므로, 해당 날짜의 완료된 항목도 포함될 수 있습니다. 향후 미완료 항목으로 제한할 계획입니다.
02 / TASK MANAGEMENT

추가부터 완료까지, 기본 기능

하나의 할 일 카드에서 입력·수정·삭제·완료 상태를 관리합니다.

기능 동작 방식
할 일 추가 제목(최대 30자), 카테고리, 선택적 마감일 입력 후 추가. 빈 제목이나 카테고리 미선택은 차단합니다.
완료·미완료 카드의 일반 영역을 클릭해 상태 변경. 완료 시 취소선이 표시되고 현재 메뉴가 즉시 갱신됩니다.
할 일 편집 ✏️ 클릭 후 제목·카테고리·마감일 수정. Enter/✔ 저장, Escape/X 취소. 완료 항목은 수정할 수 없습니다.
삭제 x 버튼을 통해 특정 항목 삭제. 현재 별도 확인창이나 실행 취소 기능은 없습니다.
마감 경고 마감일이 지났으면서 아직 완료하지 않은 항목의 날짜를 붉게 강조합니다.
알림 추가·수정·삭제·완료 처리 결과를 중앙의 임시 알림으로 보여줍니다.

워크스페이스 조건과 검색어를 함께 적용한 뒤 필요한 순서로 정렬합니다.

03 · 제목 검색

대소문자 무시
matchingList

04 · 정렬·출력

선택 기준 정렬
sortedList

정렬 기준 규칙
수동 순서 현재 배열 순서 기반으로 표시
마감일 빠른 순 마감일이 빠른 항목을 앞에 표시
마감일 늦은 순 마감일이 늦은 항목을 앞에 표시
카테고리 순 카테고리 이름을 기준으로 정렬
최신 순 항목 ID 내림차순으로 정렬
정렬 시 기본적으로 완료하지 않은 항목을 먼저 배치합니다. 카드의 ↑ / ↓ 버튼은 전체 배열 순서를 바꾸며, 이동 후 수동 정렬로 전환됩니다.
04 / ORGANIZATION

색으로 구분하는 카테고리

카테고리를 직접 만들고 색을 선택할 수 있도록 설정 모달을 구성했습니다.

  1. 카테고리 설정 버튼으로 관리 모달을 엽니다.
  2. 새 카테고리 이름을 입력하고 색상을 선택해 추가합니다.
  3. 만든 카테고리는 할 일 입력 선택창과 카테고리 칩에 반영됩니다.
  4. 카테고리 삭제 시 해당 항목의 카테고리가 미지정으로 변경됩니다.
미지정은 기본 카테고리이므로 삭제할 수 없습니다. 카테고리 색은 각 카드의 왼쪽 테두리와 태그에 표시됩니다.

HTML5CSS3Vanilla JavaScriptDOM APILocalStorage반응형 레이아웃이벤트 처리
⚙️

DOM 기반 렌더링

getTodoItemElem()이 할 일 카드를 만들고, sortAndShowList()가 표시 대상을 결정합니다.

💾

브라우저 저장

todoList와 categories를 JSON 형식으로 저장하고 다시 불러옵니다.

🕒

로컬 날짜 처리

getLocalToday()로 날짜를 계산해 오늘·예정·기한 초과 여부를 확인합니다.

🎨

읽기 편한 디자인

아이보리 배경, 세이지 그린 포인트, 카드 레이아웃과 모바일 2열 메뉴를 사용합니다. iOS Safari 날짜 입력 너비와 안내 문구 겹침 문제도 개선했습니다.

모바일 UI 개선
520px 이하에서는 메뉴를 2열로 배열하고 입력 필드를 전체 너비로 배치합니다. iPhone Safari의 날짜 입력란에는 년-월-일 안내 문구를 표시하도록 보조 스타일을 적용했습니다. 실제 Safari에서 최근 변경분의 최종 동작 검증이 남아 있습니다.

데이터는 실행 중인 브라우저 저장소에 보관됩니다. 다른 기기 동기화나 자동 백업은 제공하지 않습니다.

테스트 기준과 다음 개선 방향
