# 🌿 Todo List — Vanilla JavaScript Task Manager

[🌐 라이브 데모](https://txw-22.github.io/todo-list/) · [💻 GitHub 소스](https://github.com/txw-22/todo-list) · [📖 기능 상세 소개](docs/features.html)

> **HTML · CSS · JavaScript만으로 구현한 개인 할 일 관리 웹 애플리케이션**  
> 할 일을 추가하고, 날짜와 카테고리로 정리하고, 검색·정렬·완료 상태를 관리할 수 있습니다.

이 프로젝트는 **GitHub Pages로 배포**되어 설치 없이 체험할 수 있습니다. 프레임워크 없이 브라우저의 DOM API와 `localStorage`를 활용해 만든 To-do List입니다. 기존의 할 일 CRUD 기능을 확장해 **사이드바 워크스페이스**, **날짜별/완료 상태별 목록**, **현재 메뉴 내 검색**, **반응형 레이아웃**을 구현했습니다.

## 🖥️ 주요 기능

| 구분 | 기능 | 설명 |
| --- | --- | --- |
| 할 일 관리 | 추가 · 수정 · 삭제 | 제목, 카테고리, 마감일 입력 및 수정. 제목 최대 30자 |
| 상태 관리 | 완료 ↔ 미완료 | 할 일 항목을 클릭해 상태 전환. 완료 항목은 취소선을 표시 |
| 워크스페이스 | 전체 할 일 | 모든 항목 확인 |
| 워크스페이스 | 오늘 | 마감일이 오늘인 항목 확인 |
| 워크스페이스 | 예정된 할 일 | 마감일이 오늘 이후인 항목 확인 |
| 워크스페이스 | 완료된 할 일 | 완료 상태(`done: true`)인 항목 확인 |
| 검색 | 메뉴 내 실시간 검색 | 현재 선택한 목록에서 제목으로 검색(대소문자 무시) |
| 정렬 | 5가지 정렬 기준 | 수동 순서, 마감일 빠른 순/늦은 순, 카테고리 순, 최신 순 |
| 순서 변경 | 위/아래 이동 | 항목을 이동하면 정렬 기준을 수동 순서로 변경 |
| 카테고리 | 추가 · 삭제 · 색상 지정 | 삭제된 카테고리의 항목은 `미지정`으로 변경 |
| 일정 관리 | 마감일 표시 · 기한 초과 강조 | 마감일이 지난 미완료 항목을 붉게 강조 |
| 저장 | `localStorage` | 할 일 및 카테고리 정보를 브라우저에 저장 |
| UX | 알림 · 반응형 UI | 중앙 알림, 카테고리 모달, 사이드바 기반 레이아웃 |
| 모바일 날짜 입력 | iOS Safari 대응 | 날짜 입력 폭 보정과 `년-월-일` 안내 문구 겹침 방지 (최종 기기 확인 필요) |

## 🧭 화면 구성

- **왼쪽 사이드바:** 앱 제목, 검색창, `전체 할 일` / `오늘` / `예정된 할 일` / `완료된 할 일`, 카테고리 설정
- **오른쪽 메인:** 선택한 메뉴 제목, 할 일 추가 폼, 정렬 옵션, 할 일 카드 목록

## 🚀 실행 방법

1. 저장소를 내려받거나 복제합니다.
2. 프로젝트 루트의 `index.html`을 브라우저에서 엽니다.
3. 할 일을 추가하고 사이드바 메뉴, 검색, 정렬 기능을 사용해 봅니다.

```bash
# Git을 사용하는 경우
git clone https://github.com/txw-22/todo-list.git
cd todo-list
```

> 로컬 파일 실행 환경에서는 브라우저에 따라 `localStorage` 동작 정책이 다를 수 있습니다. 문제가 있다면 VS Code Live Server 등 로컬 개발 서버로 열어 보세요.

## 📱 반응형 UI와 iPhone Safari 대응

- **데스크톱:** 왼쪽 사이드바 + 오른쪽 작업 영역의 2단 레이아웃.
- **모바일(520px 이하):** 사이드바를 상단으로 이동하고, 워크스페이스 메뉴를 2열 그리드로 전환. 카드/입력 폼은 화면 너비에 맞게 표시합니다.
- **날짜 입력:** iOS Safari의 `input[type="date"]` 표시 차이를 고려해 폭을 제한하고, 입력 전에는 `년-월-일` 안내 문구를 겹쳐 표시합니다. 날짜 선택 후 안내 문구를 숨기려면 JavaScript의 `.has-value` 상태 갱신이 필요합니다.

> PC 브라우저 개발자 도구의 모바일 미리보기와 실제 Safari는 렌더링이 다를 수 있습니다. **실제 iPhone 17 Pro Safari에서의 날짜 선택·표시 확인**을 최종 검증 항목으로 관리합니다.

## 🧠 주요 구현 포인트

**1. 단일 렌더링 흐름**  
`sortAndShowList()`에서 현재 워크스페이스 메뉴에 맞는 항목을 고르고, 검색어로 다시 필터링한 다음, 선택한 정렬 기준으로 화면에 표시합니다.

```text
todoList → 워크스페이스 필터 → 제목 검색 → 정렬 → DOM 렌더링
```

**2. 동적 DOM 요소 생성**  
`getTodoItemElem(item)`에서 할 일 카드, 카테고리 태그, 마감일, 편집/삭제/이동 버튼을 생성하고 클릭 이벤트를 연결합니다.

**3. 브라우저 저장**  
추가·수정·삭제·상태 변경과 카테고리 변경 시 `localStorage`를 업데이트하고, 페이지 로드 시 저장 데이터를 불러옵니다.

## ⚠️ 현재 구현 범위 및 개선 예정

- `localStorage`는 **현재 브라우저/사이트 환경에 저장**되며, 다른 기기와 자동 동기화되지 않습니다.
- 현재 공유된 코드 기준, `오늘`·`예정된 할 일`은 **날짜 조건으로 필터링**하며 해당 날짜의 완료 항목도 포함될 수 있습니다. 향후 미완료 항목만 노출하도록 개선할 예정입니다.
- 검색은 현재 **할 일 제목 기준**입니다. 카테고리 통합 검색, 우선순위, 데이터 백업/복원은 향후 확장 과제입니다.
- 레거시 `filterTodoList()` 함수가 코드에 남아 있지만, 현재 검색 입력 이벤트는 `sortAndShowList()`로 연결해 사용합니다. 추후 중복 코드를 정리할 계획입니다.

## 🧪 확인한 내용과 추가 검증

PC Edge 모바일 미리보기에서 **메뉴 2열, 날짜 안내 문구 중복 제거, 할 일 입력 폼**을 확인했습니다. 사용자가 실제 iPhone Safari에서 날짜 칸의 크기와 선택 기능을 확인했지만, **최신 안내 문구 표시 수정이 실제 iPhone에서 최종 확인되었는지는 별도로 검증이 필요합니다.** 자동화 테스트를 실행했다고 주장하지 않습니다.
